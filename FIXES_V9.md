# Исправления v9: Стабилизация обучения диффузии

## Проблема
Обучение диффузии генерировало мусор несмотря на нормальную работу AE. Логи показывали:
- Огромные выбросы в `x0_bbox_mse_n` (до 47.1)
- Нестабильный loss (скачки от 0.01 до 0.09)
- MSE loss для bbox доминировал над loss для формы

## Корневые причины

### 1. Масштабная несогласованность
MSE loss для координат bbox (cx, cy, w, h) имела выбросы из-за:
- Предсказания экстремальных значений ширины/высоты
- Отсутствия маскирования для пустых слотов (padded strokes)
- Веса bbox x3, который усиливал градиенты от выбросов

### 2. Проблемы с представлением координат
- Линейное представление width/height создавало плохую обусловленность градиентов
- Малые значения ширины/высоты (<0.01) получали крошечные градиенты
- Большие значения (>0.5) доминировали в loss

### 3. Слишком агрессивный CFG scale
CFG scale=2.0 усиливает шум при нестабильном обучении

## Исправления

### 1. Huber Loss вместо MSE для bbox
```python
# Было (MSE, чувствительно к выбросам):
err = (pred_noise - noise).square()
err[..., 64:68] *= 3.0

# Стало (Huber, робастно к выбросам):
err_bbox = F.smooth_l1_loss(pred_noise[..., 64:68], noise[..., 64:68], 
                            reduction='none', beta=0.5)
```

**Преимущества:**
- Квадратичная часть только для малых ошибок (<0.5)
- Линейная часть для больших ошибок (снижает влияние выбросов)
- Более стабильные градиенты

### 2. Логарифмическое представление размеров
```python
# Было:
size = (mx - mn).clamp_min(1e-4)
return torch.cat((center, size), -1)

# Стало:
size = (mx - mn).clamp_min(1e-4)
log_size = torch.log(size + 1e-6)  # log-transform
return torch.cat((center, log_size), -1)
```

**Преимущества:**
- Выравнивает масштаб градиентов для малых и больших bbox
- Предотвращает предсказание экстремальных значений
- Улучшает сходимость

### 3. Masked Bbox Loss
```python
# Только активные штрихи участвуют в loss для bbox
err_bbox = err_bbox * valid[..., None]
err_bbox = err_bbox.sum() / (valid.sum().clamp_min(1.0) * 4)
```

**Преимущества:**
- Модель не учится предсказывать шум для пустых слотов
- Снижает общий уровень шума в генерации
- Улучшает recall presence

### 4. Снижение веса bbox и learning rate
```python
bbox_weight = 1.0  # Было 3.0
lr = 1e-4          # Было 2e-4
```

**Преимущества:**
- Баланс между обучением формы и позиции
- Более плавная сходимость

### 5. Усиленный gradient clipping
```python
grad_norm = torch.nn.utils.clip_grad_norm_(denoiser.parameters(), 0.5)  # Было 1.0
```

**Преимущества:**
- Предотвращает взрывы градиентов
- Стабилизирует обучение на ранних этапах

### 6. Сниженный CFG scale при генерации
```python
cfg_scale = 1.5  # Было 2.0
```

**Преимущества:**
- Меньше артефактов при нестабильном обучении
- Можно увеличить после сходимости

## Ожидаемые результаты

После применения исправлений:
1. `x0_bbox_mse_n` должен стать стабильным (без скачков >10)
2. Loss должен плавно убывать без резких скачков
3. Генерация должна показывать четкие структуры категорий
4. AE presence recall/rejection должны быть >0.85

## Команда для запуска

```bash
python train_vector_diffusion.py \
    --data /path/to/dataset \
    --ae-checkpoint runs/vector_ae/checkpoint.pt \
    --cache-file cache/stroke_cache.pt \
    --conditioned \
    --steps 30000 \
    --batch 16 \
    --out-dir runs/hybrid_vector_diffusion_v9
```

## Мониторинг

Следить за метриками:
- `loss` < 0.05 после 5000 шагов
- `x0_bbox_mse_n` < 5.0 и стабильно
- `ae_presence_recall` > 0.85
- `grad_norm` < 0.5

Если loss всё ещё нестабилен:
1. Проверить статистику bbox в датасете (`bb_mean`, `bb_std`)
2. Уменьшить lr до 5e-5
3. Увеличить huber_delta до 1.0
